📱 App Copa 2026

Uma aplicação móvel nativa em Flutter que traz toda a emoção da Copa do Mundo 2026 para a palma da sua mão.

Funcionalidades Principais

  • Home: Contagem regressiva, próximas partidas e destacados
  • Partidas: Visualize todas as partidas por data e fase
  • Chaves: Acompanhe o progresso das equipes no torneio
  • Classificação: Veja a tabela de classificação dos grupos

Design & UX

  • 🎨 Tema escuro moderno com acentos verde neon
  • ⚡ Interface fluida com animações suaves
  • 📱 Otimizado para todos os tamanhos de tela
  • 🚀 Performance rápida com cache local

Stack Tecnológico

  • Frontend: Flutter / Dart com Provider (state management)
  • Backend: Node.js / Express (API Proxy)
  • API Externa: Football-Data.org
  • Design: Material Design 3 + Custom UI

Este é um preview estático do app. Para experimentar o app real, clone o repositório e rode no seu dispositivo Android/iOS com Flutter.
